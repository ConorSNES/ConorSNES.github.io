Helpful info:

  • The game (should) automatically save your progress.
    • This is done using browser storage, which may vanish when your cache is cleared.
  • Shift-clicking a card will quick-move it.
  • Shift-clicking the maximise button will full-screen the game.
  • If the cards are too big or too small, you can adjust their size in the settings menu.
  • For instruction as to the game's rules, please see this text from KPatience's manual on Mod3.
  • The game does not currently work right on touch/mobile devices. I will try to fix this!
