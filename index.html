Can't be bothered to install all of KPatience on your machine for Mod3 solitaire? Running a Windows machine that can't (easily) run KPatience? Have no idea what KPatience or Mod3 solitaire even means?

I've created a web-based implementation of the Mod3 solitaire ruleset to play in the browser.

Please keep in mind it's in an early beta state as there's no in-game help system, but the game should follow the same rules as in KPatience. Also, the game will be very difficult to play on mobile/touch input (releasing touches doesn't seem to play as nice code-wise as releasing a mouse button)!
